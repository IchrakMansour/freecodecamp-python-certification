# freeCodeCamp Python Certification
 
My solutions to the labs and certification projects of the [freeCodeCamp Python Certification](https://www.freecodecamp.org/learn/python-v9/), written in pure Python 3.
 
I'm building a strong Python foundation to move from full-stack web development (React, TypeScript, Node.js) into AI engineering, so each project here is written from scratch and committed as I finish it.
 
## Projects
 
| Project | What it does | Folder |
|---------|--------------|--------|
| User Configuration Manager | Add, update, delete and view user settings stored in a dictionary | [`user-config-manager/`](./user-config-manager) |
| Budget App | Tracks spending by category and draws a spending bar chart | [`budget-app/`](./budget-app) |
| Polygon Area Calculator | `Rectangle` and `Square` classes (inheritance) to compute area, perimeter and more | [`polygon-area-calculator/`](./polygon-area-calculator) |
| Hash Table | Hash table built from scratch with a custom hash function | [`hash-table/`](./hash-table) |
| Tower of Hanoi | Recursive solver that returns every move of the puzzle | [`tower-of-hanoi/`](./tower-of-hanoi) |
 
## Concepts practiced
 
- Functions, parameters and return values
- Classes, methods and inheritance (OOP)
- Dictionaries and tuple unpacking
- Data structures (hash tables)
- Recursion and algorithms
- String methods, f-strings and text formatting
- Conditionals, loops and basic error handling
## How to run a project
 
```bash
git clone https://github.com/IchrakMansour/freecodecamp-python-certification.git
cd freecodecamp-python-certification/user-config-manager
python3 main.py
```
 
Replace `user-config-manager` with any project folder. Requires Python 3.12 or newer. No external dependencies.
